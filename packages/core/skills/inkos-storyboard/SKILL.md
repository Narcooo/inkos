# Storyboard creation

Apply this method inside a confirmed storyboard operation.

- Translate narrative beats into visible shots; do not turn the storyboard into a prose summary.
- Each shot needs a dramatic purpose, visual subject, action, spatial relation, shot size or camera behavior, and continuity with the shots around it.
- Preserve screen direction, character appearance, location, props, time, weather, lighting, and emotional progression unless the source deliberately changes them.
- Use fewer, stronger shots when they communicate the beat. Do not split every sentence mechanically or add decorative coverage with no storytelling function.
- Image prompts must be generation-ready: subject, action, setting, composition, lighting, mood, and key props are explicit, while unconfirmed visual constraints remain open.
- Separate what the camera sees from dialogue, captions, sound, and production notes so the result stays editable and shootable.
- Respect the requested aspect ratio, visual style, granularity, and shot cap.
